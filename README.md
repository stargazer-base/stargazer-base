# 🔭 推し天文台 - Stargazer Base

推しを特等席で眺め続けるための、非公式ポータルサイト（前線基地）です。
ここを拠点として、推し活をもっと楽しくする様々なWebアプリやコンテンツを展開していきます。

🌍 **Site URL:** [https://stargazer-base.app/](https://stargazer-base.app/)

## 🌟 概要 (About)

「推しへの愛を自分の手で形にしたい！」という野望から生まれたプロジェクトです。
現在はまだ「定礎（更地）」の状態ですが、今後は以下の機能を追加していく予定です。

- 📝 開発ブログ（推し天文台の観測記録）
- 📊 推し活お役立ちツール（Tier表メーカーなど）
- 🎨 その他、推しを尊ぶための様々なコンテンツ

## 🛠️ 技術スタック (Tech Stack)

モダンなWeb技術を使って、愛を込めて開発しています。

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** Supabase
- **Hosting:** Vercel

## 🤝 ご案内

本リポジトリは、サイトの土台となるポータル画面のソースコードを管理しています。
開発の裏話や、日々の推し活の様子はブログにて発信していきます！
